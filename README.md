# Capy's Squadron Macro

My macro for Anime Squadron.

## Download
Download the ZIP from [Latest Release](https://github.com/capybarnia4life/AnimeSquadronMacro/releases/latest).

Extract the entire ZIP, then run `AnimeSquadronMacro.exe`.

## Antivirus
If your antivirus blocks the macro, make sure to create an exclusion for the macro folder.

## Updates
Check the release notes for new features, changes, and fixes.
